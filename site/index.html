WARP для AmneziaWG

Регистрирует бесплатный аккаунт Cloudflare WARP и собирает конфиг с обфускацией AmneziaWG. Конфиг подходит для приложений AmneziaWG и AmneziaVPN, а также для роутеров на OpenWrt.

Получение конфига

Откуда взять ключ
Конфиг разбирается в браузере и никуда не отправляется.

        Набор для перебора endpoint
        

          
Отдельный конфиг на каждый отмеченный адрес и порт, все с этим же ключом, в одном zip-архиве. AmneziaWG импортирует архив целиком. Включайте туннели по очереди: по имени файла видно, какой вариант сработал.
